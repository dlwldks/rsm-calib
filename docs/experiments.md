## 1. 용어

### 함수 형태

입력 6개: R·G·B mean, R·G·B std. 피팅 전에 열마다 표준화 z = (x − 평균) / 표준편차.

| 이름 | 식 | 계수 수 |
|---|---|---|
| 1차 | β0 + Σ βi·zi | 7 (상수 1 + 1차항 6) |
| 2차, 교차항 없음 | 1차 + Σ βii·zi² | 13 (+ 제곱항 6) |
| 2차, 교차항 있음 (논문 식 1) | 1차 + Σ βii·zi² + Σ βij·zi·zj (i<j) | 28 (+ 제곱항 6 + 교차항 15) |
| 3차, 교차항 없음 | 2차(교차항 없음) + Σ zi³ | 19 |
| 4차, 교차항 없음 | 3차 + Σ zi⁴ | 25 |

### 지표

| 지표 | 뜻 |
|---|---|
| LOO RMSE | 표본 하나를 빼고 식을 맞춘 뒤 뺀 표본을 예측한 오차. 작을수록 예측력이 좋음 |
| 평균값만 | 식 없이 모든 점을 IoU 평균으로 예측했을 때의 LOO RMSE. 식의 LOO RMSE가 이보다 작아야 의미가 있음 |
| 정상점 | 기울기 = 0인 점 (논문 식 3). 최대점이어야 논문 절차가 성립. saddle = 안장점 |
| 상자 내 최대점 | 탐색한 범위(변수별 최소~최대) 안에서 식이 가장 높은 점 |

## 3. 계수 추정 방법 비교 (#10)

모두 2차, 교차항 있음(논문 식 1, 28계수)에 같은 기록(#5·#6·#7)을 넣고 계수 추정 방법만 변경. 새 추론 없음 (실제 IoU는 #11).

| 방법 | 개념 | 설정 |
|---|---|---|
| 최소제곱 (OLS) | 오차제곱합(MSE)을 최소화하는 계수. 논문 방식 | — |
| Ridge | 오차제곱합 + λ·(계수 제곱합). 계수 크기를 억제해 과적합을 줄임. 상수항은 벌점 없음 | λ: 0.001~100 격자에서 LOO 최소 |
| 가중 최소제곱 (WLS) | 표본별 가중치. IoU 높은 점(최적점 근처)을 더 정확히 맞추려는 목적 | w = IoU / 최대 IoU, 최소 0.05 |
| Huber | 잔차가 작으면 제곱, 크면 절댓값으로 반영. 튀는 점의 영향 축소 | ε = 1.35 |
| 붕괴 표본 제외 | IoU < 5 점을 빼고 최소제곱 | 남은 표본 29개 미만이면 풀 수 없음 |

### LOO RMSE

괄호 안은 평균값만 기준.

| 방법 | ±10% (6.68) | ±25% (10.10) | ±50% (8.60) | ±50% 125회 (7.91) |
|---|---|---|---|---|
| 최소제곱 | 7.42 | 12.46 | 17.95 | 6.79 |
| Ridge | 5.21 (λ 0.631) | 7.85 (λ 25.1) | 8.39 (λ 63.1) | 6.57 (λ 1) |
| 가중 최소제곱 | 7.15 | 14.90 | 22.23 | 9.01 |
| Huber | 16.39 | 11.50 | 13.48 | 7.07 |
| 붕괴 표본 제외 | 98.23 (30개 사용) | 풀 수 없음 (20개) | 풀 수 없음 (13개) | 28.28 (66개 사용) |

정상점 종류: 5개 방법 × 4개 기록 전부 saddle. 최대점 없음.

### 방법별 판단

| 방법 | 재추론 결과 (#11) | 판단 | 이유 |
|---|---|---|---|
| 최소제곱 | 정상점 13.33~21.12, 상자 내 최대 0~2.06 (예측 83.9~262.9) | 기준선으로 유지 | 논문 방식이므로 비교 기준. 35개 기록에서는 평균값만보다 예측이 나쁨. 상자 내 최대 예측값이 100을 넘음(과적합) |
| Ridge | ±25% 상자 내 최대 30.80, ±50% 정상점 30.73 | 유의미, 보고 대상 | 4개 기록 모두에서 평균값만보다 나은 유일한 방법. 단 ±50% 정상점은 예측 10.3, 실제 30.7로 예측이 맞지 않아 식 덕분인지 확정 불가. Ridge 탐색(#12, #13)도 개선 없음 |
| 가중 최소제곱 | 최고 15.77 | 제외 가능 | LOO가 대부분 최소제곱보다 나쁨. 정상점이 여전히 saddle. 가중치로 식 모양이 바뀌지 않음 |
| Huber | 최고 22.33 (±10% 상자 내 최대) | 제외 가능 | ±50%에서만 최소제곱보다 낫고 ±10%에서는 크게 나빠 일관성 없음. 어느 기록에서도 평균값만보다 낫지 않음. 재추론도 탐색 최고(29.34)보다 낮음 |
| 붕괴 표본 제외 | 최고 14.74 | 제외 가능 | 35개 기록에서는 28계수를 풀 수 없음(±25%, ±50%). 풀리는 경우도 LOO 28~98로 가장 나쁨 |

### 결론

방법을 바꿔도 정상점이 모두 saddle. 원인은 계수 추정 방법보다 데이터 쪽(35개 표본에 28계수, 붕괴 점이 많은 IoU 분포)으로 보임. #8·#9 결과와 같은 방향.
