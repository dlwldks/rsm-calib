## 1. 용어

### 함수 형태

입력 6개: R·G·B mean, R·G·B std. 피팅 전에 열마다 표준화 z = (x − 평균) / 표준편차.

| 이름 | 식 | 계수 수 |
|---|---|---|
| 1차 | β0 + Σ βi·zi | 7 (상수 1 + 1차항 6) |
| 2차, 교차항 없음 | 1차 + Σ βii·zi² | 13 (+ 제곱항 6) |
| 2차, 교차항 있음 (논문 식 1) | 1차 + Σ βii·zi² + Σ βij·zi·zj (i<j) | 28 (+ 제곱항 6 + 교차항 15) |
| 3차, 교차항 없음 | 2차(교차항 없음) + Σ zi³ | 19 |
| 4차, 교차항 없음 | 3차 + Σ zi⁴ | 25 |

### 지표

| 지표 | 뜻 |
|---|---|
| LOO RMSE | 표본 하나를 빼고 식을 맞춘 뒤 뺀 표본을 예측한 오차. 작을수록 예측력이 좋음 |
| 평균값만 | 식 없이 모든 점을 IoU 평균으로 예측했을 때의 LOO RMSE. 식의 LOO RMSE가 이보다 작아야 의미가 있음 |
| 정상점 | 기울기 = 0인 점 (논문 식 3). 최대점이어야 논문 절차가 성립. saddle = 안장점 |
| 상자 내 최대점 | 탐색한 범위(변수별 최소~최대) 안에서 식이 가장 높은 점 |

## 5. 계수 추정 방법 비교 (#10)

모두 2차, 교차항 있음(논문 식 1, 28계수)에 같은 기록(#5·#6·#7)을 넣고 계수 추정 방법만 변경. 새 추론 없음 (실제 IoU는 #11).

| 방법 | 개념 | 설정 |
|---|---|---|
| 최소제곱 (OLS) | 오차제곱합(MSE)을 최소화하는 계수. 논문 방식 | — |
| Ridge | 오차제곱합 + λ·(계수 제곱합). 계수 크기를 억제해 과적합을 줄임. 상수항은 벌점 없음 | λ: 0.001~100 격자에서 LOO 최소 |
| 가중 최소제곱 (WLS) | 표본별 가중치. IoU 높은 점(최적점 근처)을 더 정확히 맞추려는 목적 | w = IoU / 최대 IoU, 최소 0.05 |

### 결론

방법을 바꿔도 정상점이 모두 saddle. 원인은 계수 추정 방법보다 데이터 쪽(35개 표본에 28계수, 붕괴 점이 많은 IoU 분포)으로 보임. #8·#9 결과와 같은 방향.
