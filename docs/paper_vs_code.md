## 3. adj를 상대 비율로 본 근거

1. 논문의 θ는 0~255 스케일(Table 8: 87.32, 96.64, …). 절대값 ±0.5면 IoU 변화는 최대 ±2점 수준(toy 1차 계수 기준).
2. Figure 1 (h)의 1단계 IoU는 30대~70대 후반으로 크게 흔들림. 절대값 ±0.5로는 이 폭이 안 나옴.
3. 본문: adj를 ±0.05, ±0.01로 줄였을 때 일부 실험이 "불안정". 절대값 ±0.01픽셀은 예측이 사실상 동일해서 불안정해질 수 없음.
4. 논문은 결과를 "channel correction ratio", 식 4의 best/base 비율로 다룸. Table 8·9의 best/base 비율은 0.95~1.07.

남은 불확실성: 0.5가 반폭(±50%)인지 전폭(±25%)인지, 샘플 분포(균등/LHS/정규). `run.py broad`로 ±10%/±25%/±50%를 비교해서 정한다.

## 5. "왜 2차인가"에 대한 논문 근거 (3.3절)

- 예비 실험에서 IoU가 최적 영역 근처에서 매끄럽고 봉우리 하나인 볼록 형태.
- 자연 현상의 변수는 공간적으로 매끄럽게 변하므로 이런 반응면이 자연스럽다는 주장.
- RSM 문헌(Myers et al.)의 적용 조건과 부합.
- 검증: R², Adj.R²(0.706~0.999), F, p. 1차·3차 모델 비교, 적합결여 검정, 교차검증은 없음.

## 6. E2 타일 = toy test 폴더 (근거)

| 확인 항목 | 논문 E2 | toy test 폴더 |
|---|---|---|
| 타일 수 | 50 (오라벨 3개 제외 → 47) | 50 (train 200) |
| 클래스 | Table 4: 1~13, 18, 19 (15개) | 1~13, 18, 19 (15개) |
| snow(14) | Table 6에 없음 | 없음 |
| 침엽수 포함 타일 | 대상 타일 = 전체 47 | 8 |

침엽수 포함 타일이 8개뿐이므로, E2는 침엽수 포함 여부로 거르지 않고 전체 타일로 보정한 것으로 본다.
이전 실험(250타일 중 침엽수 포함 65타일, 그중 57개가 train)은 이 조건과 다르다.
