## AP12 (E1 후보) 확인 결과

- 영상: 512×512×3 uint8, EPSG:5186, 0.12m, 경기(GG) 지역만. 파일명 `LC_GG_AP12_<번호>_<연도>.tif`
- 라벨 Tif: 512×512 uint8, 값 = AI-HUB 코드(10 건물, 20 주차장, 30 도로, 40 가로수, 50 논, 55 비닐하우스, 60 밭, 71 활엽수, 75 침엽수, 80 나지, 95 수역, 100 기타)
- 번호 1~1000 중 Train 800 + Val 100 = 900개 (논문 Table 2의 UAV 900과 같음). 빠진 100개가 비공개 Test로 보임.
- 침엽수(75)가 있는 타일: Val 100장 중 3장, Train 800장 중 57장.
- 논문 E1은 "100타일, 침엽수 타일 32장"(Table 3). Val 100장과 다르고, 비공개 Test 100장일 가능성이 있음. 공개 데이터로 같은 100장을 만들 수 없음 → 타일 선택 방식은 저자 확인 필요.
- Val 100장 θ₀(평균 R,G,B, 표준편차 R,G,B) = 108.29 110.84 104.02 58.08 50.41 50.31

## 코드 변경

- `data.tile_key`: AI-HUB 파일명은 마지막 숫자가 연도라서 그 앞 번호로 영상·라벨을 짝지음. `--tiles` 필터도 같은 함수 사용.
- `labelmap_aihub_e1.json`: 논문 Table 4의 E1 매핑(5개 클래스) → FLAIR 19채널 인덱스. 건물 10→0, 수역 95→4, 침엽수 75→5, 활엽수 71→6, 비닐하우스 55→17, 나머지 무시.
