# 2026-10-12 연구 진행사항 — RSM 채널 캘리브레이션 효율성 검증 계획

> **상태:** 실험 계획 수립 및 기존 결과 정리 완료 / **신규 비교 실험은 아직 미실행**
>
> 기준 논문: Moon & Cho (2026), *Training-Free Lightweight Transfer Learning for Land Cover Segmentation Using Multispectral Calibration*, Remote Sensing 18(2):205, DOI: 10.3390/rs18020205.
>
> 목적: 논문의 **채널 보정 효과**와 **2차 RSM 탐색의 독립적인 기여**, **새 영상 일반화**, **재학습 대비 시간·자원·비용 효율**을 분리해 검증한다.

## 1. 10/12 핵심 연구 질문

1. **RSM이 필요한가?** 같은 보정 파라미터 탐색 범위와 평가 예산에서 무작위 탐색보다 더 빨리/높게 IoU를 향상시키는가?
2. **보정값이 실용적인가?** 보정에 쓰지 않은 타일·다른 지역에서도 IoU/mIoU가 유지되거나 개선되는가?
3. **무엇을 대체하는가?** 동일한 사전학습 U-Net 및 동일한 소량 라벨로 수행한 미세조정보다 정확도-비용 균형이 나은가?
4. **2차식 가정이 타당한가?** 28계수 완전 2차식의 홀드아웃 예측력이 충분하고 정상점이 실제 최대점인가?
5. **Decision Fusion의 비용을 감당할 수 있는가?** 클래스별 추가 추론에 따른 지연 증가를 정확도 향상이 상쇄하는가?

**판정 원칙:** 보정 후 IoU 상승만으로 RSM의 우수성을 주장하지 않는다. 모든 비교에서 탐색용 지표와 독립 평가 지표를 분리한다.

## 2. 논문 기준 방법(변경 없이 기술)

- **입력:** 채널별 RGB 평균·표준편차 여섯 파라미터 θ, 모델 가중치는 고정.
- **목적 함수:** 클래스별 U-Net 추론을 정답 라벨과 비교한 IoU.
- **수학적 방법:** 6변수, 28계수 2차 반응표면 (논문 식 (1)–(2)); 식 (3)의 정상점, 식 (4)의 비율 전이.
- **탐색 설명:** §3.3, Figure 1에서 초기 약 30개 광범위 후보(adj0 ≈ 0.5), 이후 좁은 폭(adj 0.1~0.2)에서 반복 개선, 정상점·예측/실측 차이 및 수렴 조건 사용.
- **실험별 타일:** 논문 Table 3의 Total Tiles와 Target Tiles 구분(E1: 전체 100, 보정 32; E4: 전체 100, 보정 50; E5: 전체 및 보정 150).
- **주의:** 논문은 후보 샘플링 분포와 adj의 정확한 수학적 의미를 완전히 지정하지 않는다. 코드의 LHS, 상대비율 해석, seed, 물리 경계 설정은 **우리의 구현 가정**이다. 정확히 동일한 저자 알고리즘으로 확정하지 않는다.

## 4. 추가 실험 설계(우선순위)

### P0-A. 동일 예산 최적화 비교 — “2차식 탐색의 효율성”

- **데이터/모델:** E4 D004, E5 D067 / 동일 FLAIR U-Net ResNet34 / 동일 정답·클래스·IoU 집계.
- **방법:** 원 논문 모드 RSM, Random Search, RSM+BoxMax(우리 변형). 여력이 되면 Bayesian Optimization과 미분 가능한 surrogate 목적함수 기울기법을 별도 비교.
- **예산:** 30 / 50 / 75 / 100 / 125회 **서로 동일한 실제 U-Net 추론 횟수**. 공통 탐색 범위 비교와 원 논문 절차 재현을 **별도 분석**.
- **반복:** 최소 5개 seed, 권장 10개. 기존 seed 0 결과만으로 일반화 결론 금지.
- **기록:** 실행 seed, θ0, 후보 θ, 후보 IoU, 누적 best-so-far, 실제 추론 수, wall-clock, peak RAM/VRAM, CPU/GPU 설정.
- **1차 지표:** 목표 IoU 도달까지 추론 수, 고정 예산의 best IoU 중앙값·분산, 탐색 전체 시간.
- **해석:** Random 대비 RSM의 반복적·재현 가능한 개선이 없다면 **채널 보정은 유효해도 RSM 특유의 이점은 미입증**.

### P0-B. 독립 일반화 검증 — “새 타일에서도 도움이 되는가”

- **동일 지역 분할:** 예시로 E5 150장을 105개 calibration / 45개 test로 나누되, 랜덤 픽셀/인접 타일 누수 방지를 위해 **공간 블록 단위로 분리**. 비율·블록은 데이터 분포 확인 후 확정.
- **교차 지역:** D004 → D067, D067 → D004. 각 지역의 미사용 라벨로 독립 평가하고, 논문 식 (4)의 비율 전이도 테스트.
- **비교:** 원본/기준 θ0, RSM 선택 θ, Random 선택 θ, 비율 전이 θ; 대상 클래스 IoU + 전체 mIoU + 클래스별 성능 변동.
- **라벨량:** 가능하면 10/30/50/100장에 따라 θ 탐색 성능과 홀드아웃 성능을 비교.
- **중요:** 최종 test의 정답은 θ 탐색, 조기 종료, 방법 선택에 사용하지 않는다. baseline θ의 계산 가능 입력 범위도 모든 방법에서 일치시킨다.

### P1. 동일 소량 라벨로 미세조정과 공정 비교 — “경제적인 대안인가”

- **공통 조건:** 사전학습 U-Net 동일, label 수 10/30/50장 동일, 독립 test 동일.
- **방법:** 원본 U-Net / RSM 보정 / BN-only 적응 / decoder-only fine-tuning / full fine-tuning.
- **측정:** 클래스별 IoU, mIoU, calibration+train 총 시간, CPU/GPU 사용, peak memory, 추정 클라우드 요금, 영상 1장당 추론 지연.
- **비용 판정:** 정확도 목표 도달 비용(또는 같은 비용에서의 test IoU)을 기준으로 비교. **전체 사전학습 비용**과 **동일 규모 소량 데이터 미세조정 비용**을 혼동하지 않는다.
- **비교표 구성:** 라벨 구축비가 새로 발생하는지(기존 정답지도 보유 여부)를 따로 명시한다.

### P1. 반응표면 2차식 타당성 점검 — “회귀식은 최적점을 예측하는가”

- **비교 함수:** 1차(7계수), 2차 교차항 제외(13), 논문 완전 2차(28), Ridge 2차(28).
- **기존 CSV 재활용:** LOO RMSE, 홀드아웃 θ→IoU 예측 오차, 정상점 Hessian 고유값(최대/최소/안장), 실제 추론한 θ 성능 및 예측-실측 오차.
- **자료량:** 35/50/75/100/125 관측수별 비교. 적합 R²만으로 2차 가정 검증 완료라고 판단하지 않는다.
- **구현:** [analysis/order_compare.py](../../analysis/order_compare.py), [analysis/order_by_n.py](../../analysis/order_by_n.py), [analysis/solver_compare.py](../../analysis/solver_compare.py), [analysis/reinfer_candidates.py](../../analysis/reinfer_candidates.py).
- **판정:** 2차식이 단순식보다 미래 후보를 더 잘 예측하고 탐색 효율 개선까지 연결되는지 검증.

### P2. Decision Fusion 배포 비용 — “클래스별 최적화가 실제로 이득인가”

- **비교:** 기본 1회 추론 / 공통 θ 1회 / 기본+침엽수 2회 / 기본+3클래스 4회 / 추가 클래스 수 증가.
- **측정:** 클래스별 IoU, mIoU, latency, throughput, peak memory, 정확도 변화 대비 추론 배수.
- **판정:** 하나의 대상 클래스 개선을 위해 다른 클래스가 악화되거나 지연이 과도해지는 상황을 보고한다.

## 6. 10/12 결론(가설과 확인된 사실 구분)

- **확인된 범위:** RGB 정규화 파라미터 변경으로 일부 데이터의 IoU가 개선되고 E4/E5에서는 논문 파라미터 적용 결과가 상당 부분 재현됐다.
- **아직 검증 전:** 2차 RSM이 Random이나 다른 최적화보다 계산 비용 대비 우수하다는 주장, 보정된 θ가 새로운 이미지에 안정적으로 일반화한다는 주장, 동일 라벨/동일 모델 미세조정보다 경제적이라는 주장.
- **연구 방향:** “학습된 분할 모델을 제한된 라벨·계산 자원으로 새 환경에 적응시키는 방법”으로 문제를 정의하되, 채널 보정의 효과와 **RSM이라는 특정 탐색기의 효율성은 독립적으로 평가**한다.
